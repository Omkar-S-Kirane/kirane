FERNROOT hero: image pack
base.webp        2752x700  the plain fallen log (transparent)
reveal.webp      2752x700  the same log with moss, quartz and wildflowers (identical framing)
brush-wipe.webp  900x1100  alpha mask used as the ragged leading edge of the entrance wipe

The free prompt on thinkingods.com/prompt-fernroot loads these from
https://thinkingods.com/demos/fernroot-hero/assets/
To use them offline: keep them in an assets/ folder next to index.html and change the three URLs in the prompt to assets/base.webp, assets/reveal.webp, assets/brush-wipe.webp.
(Opened straight from disk, browsers block a mask image loaded from another site; the prompt falls back to showing the log without the wipe. Self-hosting the files removes that limit.)
Free to use in your own projects. Tag @thinkingods if you build something.
